# Week 0

This week was mostly an introduction to our project, Open CMS.

## We had two meetings:
- **Meeting 1**: An introductory meet, discussing how the project will work, and what all to read upon.
- **Meeting 2**: Started off with understanding considerations while designing the architecture for a blogging website, and then continued with a look at all the technologies that will be used in making the MVP for OpenCMS like cloudflare, vercel, hugo etc.


## Points that I picked up from this week's discussions:
- What a CMS is, why would one use them.
- What system considerations one would make while developing something like this (Eg: how would you store an image, why would you store it, where would you store it... or how you would store something like likes)
